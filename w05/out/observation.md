# W05 관찰 결과

## Task 1

Dead end는 나가는 링크가 없어 rank가 사라지므로, 해당 rank를 모든 노드에 균등하게 재분배하였다. Teleportation은 dead end의 rank 유실과 spider trap의 rank 독점을 동시에 막으며, beta는 링크를 따라갈 확률이고 `1-beta`는 임의의 노드로 이동할 확률이다.

## Task 2

beta가 0.50에서 0.99로 증가할 때 반복 횟수가 14회에서 24회로 늘었는데, teleportation이 줄어들어 수렴이 느려지기 때문이다. 노드 수를 1,200에서 20,000으로 늘려도 반복 횟수는 거의 같았지만 실행 시간은 약 0.011초에서 0.336초로 증가했으며, tolerance를 `1e-6`에서 `1e-10`으로 낮추면 12회에서 20회로 늘었다.

Top-10 순위는 beta 0.50에서 0.70 사이에 처음 변한 뒤 0.70~0.99에서는 유지되었다. 따라서 전체 순위는 안정적이지만 경계에 있는 페이지는 beta 선택에 영향을 받을 수 있으므로 결과와 함께 beta를 기록해야 한다.

측정 환경은 Windows 11, Intel64 프로세서, Python 3.15.0이며, 사용 RAM과 측정 중 실행한 프로그램은 실제 환경에 맞게 기록한다.

## Task 3

Dense matrix 대신 인접 리스트와 rank 벡터를 사용하여 저장량을 `n²`에서 `n+|E|` 수준으로 줄였다. 실행 결과 worst diff는 `1.18e-15`, 약 88.5배 빠르고 174배 적은 메모리를 사용하여 dense 결과와 동일한 순위를 얻었다. Teleportation과 dead-end 보정은 모든 노드에 같은 값을 더하므로 dense 행렬 없이 출력 벡터 초기화로 처리할 수 있다.
